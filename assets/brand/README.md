# CtrlLingo · 译点品牌素材

`ctrllingo-mark.png` 是项目所有者提供的原始透明 PNG，保留原始像素与透明通道。原文件名为“CtrlDot 立体 Logo 透明版.png”；CtrlDot 是素材旧方案名，产品统一称 CtrlLingo · 译点。

Windows `.ico` 由该 PNG 转换为 16、20、24、32、48、64、128、256 像素八档图像，用于输入法列表、托盘、程序和安装器。运行 `tools/convert-brand-icon.ps1` 可重新生成。

原始方案板 `LOGO.png` 含方案编号和旧名，因此没有作为应用图标发布。品牌图用于识别本项目，不表示获得青简上游背书。
