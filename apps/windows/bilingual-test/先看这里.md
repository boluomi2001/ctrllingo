# 青简双语测试版

适用：Windows 10/11 的 x64 电脑。请复制整个测试包并完整解压，不能在压缩包里直接安装。

第四版状态：本地回归与模拟验收通过，可按步骤安装试用；真实应用上屏和真实账户仍需安装后核对。详见《第四版费用窗口与重排验证记录》。

## 已安装旧双语测试版时

先切换到其他输入法，用旧包的 `uninstall-test.cmd` 解除测试版注册并停止测试版后台，保留配置与学习数据。注销并重新登录，让应用释放旧 DLL，再用新包的 `install-test.cmd` 安装。请保留旧压缩包，需要回退时按同样步骤重新安装旧包；不要直接覆盖仍在使用的 DLL。原版青简使用不同标识，不在此升级范围内。

第三版首次运行时，会先将测试版原配置备份为 `%APPDATA%\QingjianBilingualTest\config-before-v3.toml`，然后默认关闭云联想和自动联想，避免升级后自动发送请求。原有服务地址、模型和密钥保留；之后用户主动开启的设置会保存。迁移只处理双语测试版配置，不改动原版青简的输入法配置；配置中不应抄录或公开密钥值。

## 安装与开始测试

1. 双击 `install-test.cmd`，允许 Windows 的管理员提示。查看同目录 `install-test.log` 的最终结果；出现失败请先按日志排查。
2. 安装脚本完成后注销 Windows 并重新登录，再按 `Win + Space` 选中“青简双语测试”。若脚本失败，先停止后续步骤并按日志排查；需要回退时使用旧包的卸载和安装步骤。它与原版青简使用独立的注册标识、配置目录和通信通道；不会覆盖原版。
3. 在记事本输入 `jisuanji`。正常中文输入不会自动请求整句翻译。当前高亮已有译词时按 Ctrl 直接切换到所选学习语言主栏；没有译词时按 Ctrl 请求该语言的译文。等待期间按空格不会提交内容或丢掉拼音；再按 Ctrl 回到中文后，空格可提交中文。请求出错后再按 Ctrl 重试。可在英语、日语、德语、西班牙语和越南语之间选择目标语言。
4. 编辑拼音、改选候选或翻页导致高亮变化后，主栏会回到中文；要显示新候选的学习语言译文，请重新按 Ctrl。数字键按当前主栏方向选择，点击候选则提交所点栏的文字。Ctrl+C/V/A 继续正常使用。
5. 「Ctrl 按需整句翻译」与云联想相互独立。启用按需翻译期间，释义兜底和生词本云翻译暂停；云联想缺省关闭，但可手动触发或开启自动联想，开启自动后请求可能产生费用。要设置时，从悬浮状态条的齿轮打开；也可运行 `C:\Program Files\QingjianBilingualTest\qingjian-settings.exe`。旧服务地址、模型和密钥无需修改。

## 开启 Ctrl 按需整句翻译

在测试版“设置 → 云服务”确认“整句候选翻译”已开启，并保持“中英文 → Ctrl 调换中文与目标语言候选”开启，再填写你自己的服务地址、模型和 API 密钥。服务需兼容 OpenAI 聊天接口。密钥留在电脑上，不要发到聊天里；调用可能产生费用。

只做按需翻译时，“云联想”可以保持关闭；也可以单独开启手动或自动联想。开启自动联想会发送模型请求并可能产生费用。连续输入整句拼音，例如 `wojintianxiangqugongyuan`，先核对中文句子，再按 Ctrl 请求当前高亮中文的所选学习语言译文。网络和模型处理需要时间，也不能保证所有译文都正确。

若当前没有译文，等待期间空格不提交内容，也不丢掉拼音；再按 Ctrl 回到中文后，空格可提交中文。若不想继续等，再按 Ctrl 撤销当前的按需翻译意图；已经发出的网络请求仍可能继续并产生费用，晚到译文会被忽略。改拼音、选择其他候选或翻页后，请重新按 Ctrl 请求新高亮项的译文。

按需翻译期间，释义兜底和生词本云翻译保持暂停；云联想开关不受影响。关闭按需翻译后，这两项按原设置运行。

Esc 取消、删空输入或离开输入框后，下一段组合恢复中文在左。

当前组合指尚未输出的一段拼音。若已逐词按空格输出中文，之前的文字不会自动收回并拼成整句译文。要得到整句译文，请先连续输入整句拼音。

## 查看用量与费用

右键点击青简独立托盘图标，或原右下角「中 / 英」图标，都会直接打开费用卡片；左键点击「中 / 英」仍用于切换中英文。卡片区分本输入法的 Token 与人民币费用估算、DeepSeek 官方账户余额。显示今日和自首次记账以来的累计请求及费用；缓存命中已经包含在输入 Token 中，不重复计算。只有官方 `api.deepseek.com` 上的 `deepseek-flash`、`deepseek-v4-flash` 和 `deepseek-v4-flash-vision-exp` 按 2026 年 10 月 19 日官方人民币价格估算。工作日高峰可能遇到法定节假日，或服务未提供缓存 token 明细时，费用会显示范围；用量缺失或服务不支持该价格时会显示“未知”。旧账本没有用途字段的请求归入“其他/旧记录”；升级前的记录不补算，费用账本不保存句子或 API 密钥。

第四版按确认的视觉方案采用青绿配色、叶子图标和紧凑的分组卡片，保留今日 / 累计、目标语言、详细记录与设置入口。主面板不再常驻显示成功时间；需要核对时间时打开「详细记录」。

每次打开费用卡片都会自动查询 DeepSeek 官方账户余额；没有单独刷新按钮、60 秒间隔或后台轮询。请求进行中重复打开会合并在途查询。查询中仍显示上次余额；失败时保留旧余额并标明这是上次的结果。账户余额包含该账户的其他使用和充值，不等于本输入法今日或累计花费。

## 整句候选与学习

本地模型在停键后调整整句候选。本版对较长的多词整句，会保留证据较弱时的原首选；短词继续按模型综合判断排序。主动选择备选整句时，会按实际选中的句子记住词语搭配。默认首选的学习较轻，主动改选的信号较强。紧接着删掉整句并用相同拼音改选时，撤回上一次的相关学习。

本版不会自动清空已有个人学习记录，也不能保证所有同音句都正确。若升级后仍出现「打玩」，请保留对应拼音、候选及模型设置供进一步对照；不要直接删除整个个人数据目录。

## 卸载

先切到其他输入法，双击 `uninstall-test.cmd`。确认同目录 `uninstall-test.log` 显示成功后重启 Windows，再手动删除 `C:\Program Files\QingjianBilingualTest`。脚本保留测试版配置和学习数据，位于 `%APPDATA%\QingjianBilingualTest`。

安装/卸载脚本只管理测试版，未在开发电脑执行。真实应用的 Ctrl 事件、窗口和上屏效果需要按随包《双语测试验收》在测试电脑确认，目前不能视为已通过。保留旧测试包可回装；第四版修改前的源码基线为 `1067982`，较早的回滚标签为 `test/ctrl-cost-20261020`（commit `b1207bada488b01ec23c96cbbd16c69fc39bdc6b`）。
