# 青简双语测试版

适用：Windows 10/11 的 x64 电脑。请复制整个测试包并完整解压，不能在压缩包里直接安装。

## 已安装旧双语测试版时

先切换到其他输入法，用旧包的 `uninstall-test.cmd` 解除测试版注册并停止测试版后台，保留配置与学习数据。注销并重新登录，让应用释放旧 DLL，再用新包的 `install-test.cmd` 安装。请保留旧压缩包，需要回退时按同样步骤重新安装旧包；不要直接覆盖仍在使用的 DLL。原版青简使用不同标识，不在此升级范围内。

## 安装与开始测试

1. 双击 `install-test.cmd`，允许 Windows 的管理员提示。查看同目录 `install-test.log` 的最终结果；出现失败请先按日志排查。
2. 安装成功后注销 Windows 并重新登录，按 `Win + Space` 选中“青简双语测试”。它与原版青简使用独立的注册标识、配置目录和通信通道；不会覆盖原版。
3. 在记事本输入 `jisuanji`。正常中文输入不会自动请求整句翻译。当前高亮已有译词时按 Ctrl 直接切换到英文主栏；没有译词时按 Ctrl 请求翻译。等待期间按空格不会提交内容或丢掉拼音；再按 Ctrl 回到中文后，空格可提交中文。请求出错后再按 Ctrl 重试。
4. 编辑拼音、改选候选或翻页导致高亮变化后，主栏会回到中文；要显示新候选的英文，请重新按 Ctrl。数字键按当前主栏方向选择，点击候选则提交所点栏的文字。Ctrl+C/V/A 继续正常使用。
5. 启用「整句候选翻译」期间，自动云联想、释义兜底和生词本云翻译都会暂停，即使当前主栏是中文或没有正在组句。要设置时，从悬浮状态条的齿轮打开；也可运行 `C:\Program Files\QingjianBilingualTest\qingjian-settings.exe`。旧服务地址、模型和密钥无需修改。

## 开启 Ctrl 按需整句翻译

在测试版“设置 → 云服务”确认“整句候选翻译”已开启，再填写你自己的服务地址、模型和 API 密钥。服务需兼容 OpenAI 聊天接口。密钥留在电脑上，不要发到聊天里；调用可能产生费用。

只做按需翻译时，“云联想”可以保持关闭。连续输入整句拼音，例如 `wojintianxiangqugongyuan`，先核对中文句子，再按 Ctrl 请求当前高亮中文的英文翻译。网络和模型处理需要时间，也不能保证所有译文都正确。

若当前没有译文，等待期间空格不提交内容，也不丢掉拼音；再按 Ctrl 回到中文后，空格可提交中文。若不想继续等，再按 Ctrl 撤销当前的英文请求意图；已经发出的网络请求仍可能继续并产生费用，晚到译文会被忽略。改拼音、选择其他候选或翻页后，请重新按 Ctrl 请求新高亮项的译文。

“整句候选翻译”启用期间，自动云联想、释义兜底和生词本云翻译都会暂停；关闭此开关后，这些功能按旧设置运行。

Esc 取消、删空输入或离开输入框后，下一段组合恢复中文在左。

当前组合指尚未输出的一段拼音。若已逐词按空格输出中文，之前的文字不会自动收回并拼成整句英文。要得到整句译文，请先连续输入整句拼音。

## 查看用量与费用

右键点击右下角「中 / 英」按钮可查看「本输入法今日估算」和 DeepSeek 官方账户余额；左键仍用于切换中英文。今日估算统计新版启用后的请求次数和 token；只有官方 `api.deepseek.com` 上的 `deepseek-flash`、`deepseek-v4-flash` 和 `deepseek-v4-flash-vision-exp` 按 2026 年 10 月 19 日官方人民币价格估算。工作日高峰可能遇到法定节假日，或服务未提供缓存 token 明细时，费用会显示范围；用量缺失或服务不支持该价格时会显示“未知”。旧数据不补算，费用账本不保存句子或 API 密钥。

打开余额菜单时才会查询 DeepSeek 账户，所有应用共用 60 秒查询间隔；等待满 60 秒后重新打开菜单可触发新查询。余额不等于今日扣费。「用量与费用…」对话框打开时显示快照，关闭后重新打开可刷新。

## 卸载

先切到其他输入法，双击 `uninstall-test.cmd`。确认同目录 `uninstall-test.log` 显示成功后重启 Windows，再手动删除 `C:\Program Files\QingjianBilingualTest`。脚本保留测试版配置和学习数据，位于 `%APPDATA%\QingjianBilingualTest`。

安装/卸载脚本只管理测试版，未在开发电脑执行。真实应用的 Ctrl 事件、窗口和上屏效果需要按随包《双语测试验收》在测试电脑确认，目前不能视为已通过。保留旧测试包可回装；本轮源码回滚基线为 tag `backup/bilingual-live-before-ondemand-20261019`（commit `2c0ed70`）。
