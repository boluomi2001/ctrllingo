# 青简双语测试版

适用：Windows 10/11 的 x64 电脑。请复制整个测试包并完整解压，不能在压缩包里直接安装。

## 安装与开始测试

1. 双击 `install-test.cmd`，允许 Windows 的管理员提示。查看同目录 `install-test.log` 的最终结果；出现失败请先按日志排查。
2. 安装成功后注销 Windows 并重新登录，按 `Win + Space` 选中“青简双语测试”。它与原版青简使用不同的注册标识、配置目录和通信通道。
3. 在记事本输入 `jisuanji`，有英文释义的候选默认中文在左、英文在右。单独按下并松开 Ctrl：英文在左、中文在右。按空格输出高亮项左侧内容；再按 Ctrl 可切回中文。
4. 非首位候选用数字键选择，或先用上下方向键移动高亮、再按空格。翻页后同样生效。点击左栏输出左栏文字，点击右栏可输出右栏中文。Ctrl+C/V/A 继续正常使用。
5. 如需设置，从悬浮状态条的齿轮打开；也可运行 `C:\Program Files\QingjianBilingualTest\qingjian-settings.exe`。

## 开启整句实时翻译

在测试版“设置 → 云服务”确认“整句候选翻译”已开启，再填写你自己的服务地址、模型和 API 密钥。服务需兼容 OpenAI 聊天接口。密钥留在电脑上，不要发到聊天里；调用可能产生费用。

只做翻译时，“云联想”可以保持关闭。测试版默认在停键 350 毫秒后准备请求，两次请求至少间隔 600 毫秒；结果还需要网络和模型处理时间。它会随着当前未上屏的整句中文更新，不能保证零延迟或任何模型都翻译正确。

连续输入整句拼音，例如 `wojintianxiangqugongyuan`，先核对中文句子是否正确。右侧英文返回后，按 Ctrl 调换，再按空格输出整句英文。若中文候选本身不正确，应先改拼音或选择正确句子；翻译模型收到的是当前中文候选。

“暂无译文”表示当前候选尚无可用英文，不会把该提示或中文误当英文上屏。可稍候、选有译文的候选，或按 Ctrl 切回中文。Esc 取消、删空输入或离开输入框后，下一段组合恢复中文在左。

当前组合指尚未输出的一段拼音。若已逐词按空格输出中文，之前的文字不会自动收回并拼成整句英文。要得到整句译文，请先连续输入整句拼音。

## 卸载

先切到其他输入法，双击 `uninstall-test.cmd`。确认同目录 `uninstall-test.log` 显示成功后重启 Windows，再手动删除 `C:\Program Files\QingjianBilingualTest`。脚本保留测试版配置和学习数据，位于 `%APPDATA%\QingjianBilingualTest`。

安装/卸载脚本只管理测试版，未在开发电脑执行。真实应用的 Ctrl 事件、窗口和上屏效果需要按随包《双语测试验收》在测试电脑确认。
