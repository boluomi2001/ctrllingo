## 当前下载入口

页首、首屏和手机菜单的“立即下载”链接直接指向已核实的 CtrlLingo 0.1.1 Windows x64 安装器。手机菜单点击后收起菜单并将焦点还给菜单按钮。页面只发起浏览器下载，不会运行安装器；底部发布说明与源码许可链接仍保留。

替换后补测：实际 Edge 的桌面首屏点击、顶部键盘 Enter、手机首屏和菜单触屏点击均触发正确安装包的真实下载事件；手机菜单关闭 / 焦点返回通过，磁吸及 Ctrl / Space 演示保留。1440、1024、768、390、375px 无横向溢出或导航碰撞，已生成新的 1440 / 390px 截图，控制台无 warning / error。下载事件测试在开始后取消副本，不视为全量下载完成。

远端 HEAD 返回 200、正确文件名及 159,538,445 字节；Range 请求返回 206 和有效 EXE 文件头。完整浏览器下载在本机停滞；独立 HTTPS GET 在 120 秒后超时，仅收到 965,034 字节，未计算完整文件摘要。GitHub API 的发布资产摘要已核实，但本轮不能宣称远端全量下载成功；最终用户网络中的下载速度和完整性仍需测试。上述修改后的证据另附于“CtrlLingo-立即下载验收”，阶段 04 原始截图 / 归档保留为历史版本。
