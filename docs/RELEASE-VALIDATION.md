# CtrlLingo 0.1.0 发布验收

发布目标：Windows x64 主程序与设置程序，以及供 32 位应用加载的 x86 TSF DLL。其他平台保留上游源码，不在本次发行范围内。

本文随本次源码与安装包发布。最终构建和验证结果在下方更新；继承的青简验证记录属于历史证据，不自动适用于译点。

## 发布门槛

- 从同一份源码构建 Server、设置程序、x64/x86 TSF，固定 Cargo.lock。
- Rust 格式检查、相关单元及协议回归、Clippy 检查。
- 独立配置和本地模拟服务验证五语言按需翻译、取消与过期响应、费用账本和卡片交互。
- 校对软件品牌、输入法身份、互斥体、命名管道与用户目录；不与青简或旧双语测试版共用。
- 检查安装包、同源源码快照、许可与 SHA-256 清单。
- 原生安装/升级/卸载、真实应用 TSF 按键和上屏、真实服务账户尚需单独验证。未通过前 GitHub 发布保持 prerelease；不把构建成功当成稳定性证明。

## 当前限制

发行文件没有受信任的代码签名，`uiAccess=false`。系统搜索、商店应用等窗口可能遮挡候选窗；安全策略也可能阻止运行。请勿以关闭系统保护作为解决步骤。

费用为本机估算，内置价格表可能过期；以服务商账单为准。真实余额没有用虚构数据替代验收。

## 2026-10-23 本地验收结果

- Rust 1.96.0；x64/i686 Windows GNU 工具链。两个架构的 TSF 均从本次源码重建。
- 相关组件 release 回归：793 项通过、0 失败（26 个测试套件，含空 doctest 套件）。
- `cargo fmt --all --check` 与相关组件 `cargo clippy --release --locked --all-targets -- -D warnings` 通过。
- 五语言 en/ja/es/vi/de 本地模拟接口验收通过：正常输入不自动发整句翻译、等待空格保护、改字后晚结果失效、Unicode 结果提交与缓存复用。
- 费用账本验证输入 200、输出 40、缓存输入 80、总 token 240；缓存输入计入输入总量，不重复累加。
- 费用窗口消息级交互通过：今日/累计、目标语言菜单、配置写入、详细记录、关闭后托盘重开、同目录设置程序启动；125% 缩放截图为 450×535。
- x64/x86 DLL 系统加载及四个 COM 导出检查通过，没有调用注册入口。
- 设置程序生成 31 张离屏预览；人工检查了品牌侧栏、关于页和费用窗口。离屏预览不是物理鼠标键盘验收。
- 实际程序与隔离暂存文件的 SHA-256 一致，详情见 [机器可读记录](validation/0.1.0.json)。

排查记录：首次 HTTP 回归受到本机系统代理影响，加入 `NO_PROXY=localhost,127.0.0.1,::1` 后复测通过；截图脚本先等待费用窗口完成 `WM_PRINTCLIENT` 绘制，避免把未完成的截图判成空白。检查未放宽行为断言。

原生安装、升级、卸载和真实应用 TSF 上屏仍未执行；没有使用真实 API 密钥或查询真实账户余额。因此本次只发布完整的预发布安装包，不宣称稳定版。
