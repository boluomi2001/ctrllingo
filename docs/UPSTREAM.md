# 上游来源与归属

CtrlLingo · 译点是由项目所有者 `boluomi2001` 维护的独立 Windows 二次开发版本，不是 Qingjian 官方产品，也未获上游背书。

本项目基于 [Qingjian 上游仓库](https://github.com/qingjian-team/qingjian)提交 [`c97ff2b61933d6fcd845ee4f4f470faf3ea83bf6`](https://github.com/qingjian-team/qingjian/commit/c97ff2b61933d6fcd845ee4f4f470faf3ea83bf6)，并包含当前工作树第四版优化。引擎、既有功能和上游代码的作者归属仍属于上游原作者及各自权利人；CtrlLingo 不主张原创全部引擎。

项目保留 [GPL-3.0-or-later](../LICENSE) 许可和上游版权声明。发布时还应保留随包数据及第三方依赖各自要求的来源与许可信息。内部 crate 继续使用 `qingjian` 名称，以保持源代码和依赖关系一致。

为便于查阅，上游 README 的副本位于 [`docs/upstream/README.zh-CN.md`](upstream/README.zh-CN.md)。该文件是上游材料副本，不代表译点功能、版本或发布状态。
