# 隐私说明

本说明描述 CtrlLingo Windows 版本当前源码和安装默认配置中的数据处理方式。云请求由你主动开启相应功能或触发相应操作后发送。

## 本机处理与输入日志

拼音查询、随包词库、本地整句模型和候选学习在本机运行。输入日志记录按键、上屏内容、候选和选择等信息，但在 CtrlLingo 通用缺省配置及 Windows 安装器默认配置中均为关闭。开启后，日志保存在 `%APPDATA%\CtrlLingo\input-log.jsonl`；它不是匿名数据，不要未经检查就公开。可以在设置的高级页关闭或清空日志。关闭记录不会自动删除之前写入的文件。

配置、密钥、学习数据和统计保存在 `%APPDATA%\CtrlLingo`。运行日志在 `%LOCALAPPDATA%\CtrlLingo\logs`。机器级 TSF 图标在 `%ProgramData%\CtrlLingo`。卸载会移除程序和 TSF 注册，但保留用户目录中的配置和学习数据。

## 云请求

云联想默认关闭，`automatic` 默认关闭。首次启动迁移也会关闭已有配置中的云联想和自动请求；之后可由你在设置中主动开启。

按需翻译与云联想使用同一兼容 API 配置，但触发条件不同。按 Ctrl 请求翻译时，程序发送当前拼音组合中**高亮的中文候选文本**，不会读取其他应用里选中的已有文字，也不会把周围上下文一并发送。即使 `predict.enabled=false`（云联想关闭），按 Ctrl 触发的候选翻译仍会请求服务，因为它由单独的 `sentence_translation` 设置控制。云联想开启后才会把光标附近的输入上下文发送给服务商；自动联想还要求 `automatic` 开启。

接收方是你在设置中填写的兼容 API 服务，不是 CtrlLingo 项目服务器。接口服务商如何保存、处理或传输请求内容，由该服务商的隐私政策决定。不要对敏感内容发起云请求。请求可能产生服务商费用。

打开费用面板时，程序可能向受支持的 DeepSeek 官方接口发送带认证信息的余额查询请求。费用账本和查询结果保存在本机；本机费用为估算，不等同服务商账单或账户余额。

## API 密钥与诊断材料

在设置页填写的 API 密钥保存在 `%APPDATA%\CtrlLingo\config.toml` 的本机配置字段中；也可将密钥放在环境变量 `CTRLLINGO_API_KEY` 中。配置文件不是 Windows 凭据库，不应作为普通文本分享或提交到 issue。

运行日志写入前会尝试遮盖已加载且长度至少 8 字节的 API 密钥。设置中的“打包日志”会将运行日志与抹去 `api_key` 字段值的配置副本打包；它不包含输入日志文件。日志掩码并不覆盖所有本地文件、崩溃转储或你手动复制的文本。请在分享诊断包前自行检查内容，不要附上 API 密钥或私人输入。

当前 Windows 版本不会向 Qingjian 上游发起自动更新检查。“关于”页中的入口会由你手动打开 CtrlLingo 的 GitHub Releases 页面。

## 删除数据

你可以关闭云功能、关闭输入日志并清除既有输入日志。若要删除配置、API 密钥和学习数据，请先卸载，再删除 `%APPDATA%\CtrlLingo`。运行日志可另行删除 `%LOCALAPPDATA%\CtrlLingo\logs`；卸载程序不会自动清除这些用户数据目录。
