整句候选翻译目前仅在 Windows 版提供。它需要联网，并使用「云服务」页中填写的 AI 服务。

Windows 版可在候选栏中按需查看当前中文句子的英文翻译。启用此功能后，普通中文组句不会自动请求整句翻译；需要英文时按 Ctrl。此功能不会改变中文候选的排序。

## 开启

在「设置 → 云服务」打开“整句候选翻译”，再填写服务地址、模型与 API 密钥。

服务须兼容 OpenAI 聊天接口。密钥只保存在本机，不随配置文件导出。

旧配置可以继续使用，原有服务地址、模型、密钥和其他开关不会被自动改动。候选若已有译词，按 Ctrl 会立即切换英文与中文主栏；若当前高亮候选还没有译词，按 Ctrl 会请求翻译。等待期间按空格不会提交内容或丢掉拼音。

等待时再按 Ctrl 会撤销当前的英文请求意图并切回中文，之后可按空格提交中文。晚到的译文会被忽略；已经发出的网络请求仍可能继续并产生费用，无法保证中止。请求出错后可再按 Ctrl 重试。编辑拼音、改选候选或翻页造成高亮变化时，主栏会回到中文；需要英文时请在新的高亮候选上重新按 Ctrl。数字键按当前主栏方向提交候选；点击候选则提交所点栏里的文字。

启用“整句候选翻译”期间，自动云联想、释义兜底和生词本云翻译都会暂停，不受当前主栏或组句是否结束影响。关闭此开关后，其他功能按原有设置运行。

## 使用

原有 `Ctrl + 数字` 译词快捷键仍可使用。

## 发送的内容

手动请求只发送当前高亮的一条中文候选和目标语言，不发送拼音、光标前后上下文或其他候选。密码框和应用标为私密的输入框中不会发送。

输入继续变化时，旧请求的结果会丢弃。上屏、删空拼音或按 `Esc` 取消输入时，旧结果会被忽略；已经发出的网络请求仍可能继续并产生费用。

## 查看用量与费用

右键点击右下角的「中 / 英」按钮，可查看「本输入法今日估算」和 DeepSeek 官方账户余额。左键点击该按钮仍只切换中英文。

今日估算从新版启用后开始记录请求次数和 token；旧记录不补算。只有官方 `api.deepseek.com` 上的 `deepseek-flash`、`deepseek-v4-flash` 和 `deepseek-v4-flash-vision-exp` 会按 2026 年 10 月 19 日的官方人民币价格估算。工作日高峰可能遇到法定节假日，且有些服务不提供缓存 token 明细，因此费用会显示合理范围或“未知”。DeepSeek 账户余额是账户信息，不等于今天的实际扣费；旧平台曾显示的 0.66 元不会回算进新账本。

打开余额菜单时才会后台查询；所有应用共用 60 秒查询间隔。等待满 60 秒后重新打开余额菜单可触发新查询。「用量与费用…」对话框显示打开时的快照，关闭后重新打开可刷新。

费用记录不保存输入句子或 API 密钥。
