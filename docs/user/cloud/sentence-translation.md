整句候选翻译目前仅在 Windows 版提供。它需要联网，并使用「云服务」页中填写的 AI 服务。

Windows 版可在候选栏中按需查看当前中文句子的学习语言译文，支持英语、日语、德语、西班牙语和越南语。启用此功能后，普通中文组句不会自动请求整句翻译；需要译文时按 Ctrl。此功能不会改变中文候选的排序。

## 开启

在「设置 → 云服务」打开“整句候选翻译”，并保持「中英文 → Ctrl 调换中文与目标语言候选」开启，再填写服务地址、模型与 API 密钥。

服务须兼容 OpenAI 聊天接口。密钥只保存在本机，不随配置文件导出。

首次运行第三版时，测试版会先备份旧设置为 `%APPDATA%\QingjianBilingualTest\config-before-v3.toml`，并默认关闭云联想与自动联想；原有服务地址、模型和密钥会保留。之后由用户主动开启的设置会保存。候选若已有所选学习语言的译词，按 Ctrl 会立即切换译文与中文主栏；若当前高亮候选还没有译词，按 Ctrl 会请求翻译。等待期间按空格不会提交内容或丢掉拼音。

等待时再按 Ctrl 会撤销当前的按需翻译意图并切回中文，之后可按空格提交中文。晚到的译文会被忽略；已经发出的网络请求仍可能继续并产生费用，无法保证中止。请求出错后可再按 Ctrl 重试。编辑拼音、改选候选或翻页造成高亮变化时，主栏会回到中文；需要译文时请在新的高亮候选上重新按 Ctrl。数字键按当前主栏方向提交候选；点击候选则提交所点栏里的文字。

Ctrl 按需翻译与云联想相互独立。云联想默认关闭，但可手动触发或开启自动请求；开启自动联想会发送模型请求并可能产生费用。按需翻译启用期间，释义兜底和生词本云翻译保持暂停，不受当前主栏或组句是否结束影响。关闭按需翻译后，这两项按原设置运行。

## 使用

原有 `Ctrl + 数字` 译词快捷键仍可使用。

## 发送的内容

手动请求只发送当前高亮的一条中文候选和所选学习语言，不发送拼音、光标前后上下文或其他候选。密码框和应用标为私密的输入框中不会发送。

输入继续变化时，旧请求的结果会丢弃。上屏、删空拼音或按 `Esc` 取消输入时，旧结果会被忽略；已经发出的网络请求仍可能继续并产生费用。

## 查看用量与费用

右键点击青简独立托盘图标或原「中 / 英」按钮，会直接打开费用卡片。卡片区分本输入法请求的 Token 与人民币估算花费、DeepSeek 官方账户余额；后者包含账户的其他使用和充值，不等于本输入法花费。左键点击「中 / 英」按钮仍只切换中英文。

卡片显示今日和自首次记账以来的累计请求、Token 与费用。缓存命中已包含在输入 Token 中，不重复计算；旧账本没有用途字段的请求归入其他/旧记录。只有官方 `api.deepseek.com` 上的 `deepseek-flash`、`deepseek-v4-flash` 和 `deepseek-v4-flash-vision-exp` 会按 2026 年 10 月 19 日的官方人民币价格估算。工作日高峰可能遇到法定节假日，且有些服务不提供缓存 token 明细，因此费用会显示合理范围或“未知”。

每次打开卡片都会自动查询官方余额；没有单独刷新按钮、60 秒间隔或后台轮询。查询中重复打开会合并在途查询。查询中保留上次余额并显示其更新时间；失败时保留旧余额并标明失败。卡片统计来自后台缓存的账本汇总。

费用记录不保存输入句子或 API 密钥。
