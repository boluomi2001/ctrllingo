本机拼音转换和词库查询在电脑上完成。使用按需翻译、云联想或其他云服务功能时，相关文本会直接发送到你配置的 AI 服务商；译点没有自己的翻译服务器。是否启用云请求由你控制，服务商的数据处理规则和费用适用其自身政策。

## 检查更新

Windows 版不会自动请求青简更新服务。设置窗口的「关于」页提供手动打开 CtrlLingo 项目 GitHub Releases 的入口；打开网页时，浏览器会按其正常方式连接 GitHub。译点不在后台检查或下载更新。

以下 macOS 等更新说明属于继承自上游的资料，不代表译点已发行或验收这些平台。

## 本机文件

Windows 用户数据保存在 `%APPDATA%\CtrlLingo`（在资源管理器地址栏中输入即可），运行日志保存在 `%LOCALAPPDATA%\CtrlLingo\logs`。系统级 TSF 图标资源位于 `%ProgramData%\CtrlLingo`。下面列出的用户数据均在本机；具体内容取决于你使用的功能：

| 文件 | 内容 | 可能包含输入内容 |
|---|---|---|
| `config.toml` | 输入、云服务及其他设置；配置中的 API 密钥以明文保存在本机 | 可能含 API 密钥 |
| `user.tsv`、`user-words.tsv`、`user-choices.tsv` | 词频、用户词和特定拼音下选择过的词 | 选过的词和拼音 |
| 其他 `user-*.tsv` | 学习到的词、拼音、释义和接续偏好 | 视文件类型，可能包含输入过的词或拼音 |
| `vocab-log.tsv`、`user-vocab.tsv` | 生词本中的中文、译文、例句和学习记录 | 可能包含中文与译文 |
| `usage-hourly.tsv` | 按小时汇总的输入及上屏统计 | 统计数字，不是原始文字 |
| `api-usage.json`、`api-usage-hourly.tsv`、`api-cost-ledger.json` | API 请求、用量与费用估算记录 | 用量和金额，不是原始输入文字 |
| `input-log.jsonl` | 可选的输入事件日志 | 启用后可能包含按键、拼音、候选及上屏文字 |
| `dicts/`、`themes/`、`codes/` | 用户导入的词库、主题和码表 | 取决于导入内容 |

云服务密钥可保存在 `config.toml` 的设置中，也可通过环境变量 `CTRLLINGO_API_KEY` 提供。密钥不会加密保存；分享配置前应检查并移除密钥。译点不会将这些本机文件自动上传。

上述文件并非都以相同方式写入；不要把整个数据目录视为可安全分享的诊断包。卸载默认保留个人数据，清除方法见[卸载](uninstall.md)。

## 云联想发什么

Windows 版的云联想默认关闭，自动联想也默认关闭。只有在你启用云联想并触发对应功能时，输入拼音、当前组合中的候选或功能所需文本才会发送给配置的 AI 服务商。关闭 `predict.enabled` 会关闭云联想；它不会关闭单独的按需整句翻译。

- 按需整句翻译：按 Ctrl 时，将当前拼音组合中高亮的中文候选和目标语言发给服务商。它不是读取任意应用里已选中的文字，也不发送应用周围的文本。此请求由 `sentence_translation` 控制，即使 `predict.enabled=false` 也可能发送。
- 云联想：启用后，相关拼音与本机候选会按功能请求发送。自动联想另由 `automatic` 控制；关闭自动联想不等于关闭手动触发的云请求。
- 其他云功能（例如译词补充、生词本整句翻译或测试连接）会在各自触发时发送相应内容。是否启用这些功能取决于设置。

请求从本机直接发往你配置的服务商，不经过译点的服务器。服务商可能按其政策记录或处理请求，并可能产生费用。费用估算与 API 余额是不同信息：本机账本是根据可获得的用量及价格做估算，不代表服务商账户的实时余额。

旧版 macOS、Linux 云请求说明属于上游继承资料，不代表译点已发行或验收这些平台。

## 整句候选翻译发什么

Windows 版按 Ctrl 请求翻译当前拼音组合中高亮的中文候选，并发送目标语言。它不会读取其他应用中已有的选区或周围上下文。译点将候选文本和目标语言发给当前配置的 AI 服务商；请求会产生网络流量，也可能产生服务商费用。`predict.enabled` 关闭时，此项仍可单独工作；关闭「整句候选翻译」后不再发送此类请求。

## 输入日志

Windows 版默认关闭输入日志（`general.input_log = false`）。打开后，日志可能记录输入事件、拼音、候选、选择结果、应用标识等信息，因此可能包含敏感输入。它保存在本机 `%APPDATA%\CtrlLingo\input-log.jsonl`，不会自动上传；诊断打包也不包含此文件。

- 开关：「设置 → 高级」中的「记录输入日志」。
- 清空：在同一页选择「清空输入日志」。
- 如需向他人提供日志，请先自行检查并删除敏感内容；不要假设日志只包含匿名统计。

## 运行日志

Windows 版运行日志位于 `%LOCALAPPDATA%\CtrlLingo\logs`，包括 Server、TSF 和设置程序的日志。默认日志级别用于常规运行记录；开启「详细日志」后可能增加输入处理及请求排查细节。排查后可关闭详细日志。

「设置 → 高级」的「打包到桌面」会导出运行日志和配置副本。导出流程会抹去配置中 `api_key = ...` 行的密钥值，但脱敏范围有限：它不应被视为对所有个人信息或其他凭据的全面清理。分享前请自行检查压缩包；输入日志 `input-log.jsonl` 不包含在该包中。
