# 第四版费用窗口与重排验证记录

本版完成费用窗口调整、较长整句的弱优势保护，以及备选整句的词语搭配学习。本机回归、正式构建、五语言桌面模拟和费用窗口消息级交互验收均已通过，可按随包步骤安装试用。真实应用上屏、真实账户余额及物理鼠标键盘操作仍未验证。当前干净环境没有复现「打完」被改成「打玩」，因此不能把本版描述为已查明并修复用户原有环境的根因。

## 需求与证据

- 依据用户提供的「青简用量余额面板.png」及[共享对话](https://chatgpt.com/share/6ad8cd56-a89c-83ea-9efb-4298a7655f4c)，采用青绿、暖白、圆角分组及叶子图标；缩小窗口，隐藏主面板成功时间，保留今日 / 累计、语言、详细记录与设置。
- 共享对话中的诊断分析提出了模型误排与错误学习的可能性。原始诊断附件未直接取得，不能把转述当作当前源码与当前数据下的复现证据。
- 明确的实现、盘点与评分探测交由 GPT-6 Luna 执行；范围判断、代码审查、回归比较与最终验收由主 agent 完成。
- 修改前源码基线：`1067982`。保留 `target/backups/before-v4-source.zip` 和第三版原包；没有安装、卸载或注册输入法，没有改动用户真实学习记录、配置与密钥。

## 最终改动

| 范围 | 最终行为 |
| --- | --- |
| 费用窗口 | 逻辑尺寸 360 × 428；最终正式构建在本次 125% 屏幕下实测 450 × 535 像素。原生窗口仍不激活，使用现有统计快照，没有把参考图数字写入界面。 |
| 余额状态 | 主面板隐藏成功时间；查询中、失败和上次余额状态继续区分，完整信息保留在详细记录。请求、费用、缓存及余额的计算与查询规则沿用原实现。 |
| 重排保护 | 仍按原混合分稳定排序，仅在原首选与模型胜者均为多词、原首选至少四音节且胜者相对优势小于 1.0 时保留原首选。其余候选保持混合分顺序；不把神经分写回路径分。 |
| 备选学习 | 按实际选中整句匹配当前前三条词图路径；默认整句的内部搭配学习一次，主动改选学习两次。保留原接续学习规则；删掉整句并以同拼音重选时按实际次数撤回。匹配不到路径时不猜测词序列。 |

门槛是本版保守策略，不是经过大规模评测证明的最优参数。试验中把保护应用到全部长度会让「同音词」退步，已放弃该方案并收窄到上述范围。模型直接生成但无法匹配词图路径的句子，不在本次词图搭配学习修复范围内。原有错误学习也不会因升级自动消失。
