# 双语版本验证记录

本文记录备份版本 `2c0ed70` 的实时翻译验收，不代表后续 Ctrl 按需版本已通过。新版本的结果见《Ctrl按需翻译与费用验证记录》。

## 版本与隔离

基于官方仓库提交 `c97ff2b61933d6fcd845ee4f4f470faf3ea83bf6` 的独立修改副本，属于个人测试版。Windows 中的名称为“青简双语测试”。测试版的注册标识、命名管道、设置窗口互斥体、用户配置、日志和图标目录均与原版分开。开发过程中未执行安装或注册脚本，也未替换本机原版的程序、词库或配置。

完整产品数据按源码中的 `tools/release/data.lock` 核验，数据版本为 `data-v7`，SHA256 为 `e259f8bc2a5456c92484c5d4362ca56b3e46b3d2e1a0d463788091a039d79e40`。

## 已完成的自动验证

在 Windows x64 开发环境（系统版本 `10.0.26200.0`）使用 Rust 1.96.0，对核心、平台、翻译服务、设置程序、Windows 后台与 TSF 六个相关组件执行发布模式测试：**705 项通过，0 项失败**。

其中包含 18 项新增交互与异步测试：Ctrl 按下不触发、松开后调换及还原、空格输出英文、新组合恢复中文、非首位高亮、翻页后数字选择、鼠标两栏、禁用开关、空缓冲、英文输入模式、无译文保护、Ctrl+C 放行、整句输出、返回顺序颠倒、等待译文、Esc、删空/失焦与私密输入。另有 2 项核心边界测试核对展示副本保留原始拼音范围，以及中文释义或空释义不能冒充英文输出。

翻译服务的 39 项测试使用真实本机 HTTP 模拟接口，核对请求、用量记录、兼容重试、防抖、间隔、缓存、取消和失败暂停。测试进程设置 `NO_PROXY=localhost,127.0.0.1,::1`，避免本机系统代理影响模拟接口；未更改电脑代理设置，未使用付费服务或用户密钥。

安装、卸载与打包脚本已通过 Windows PowerShell 5.1 的静态语法解析。脚本在测试电脑执行时才会请求管理员权限；卸载只管理测试目录中的进程和 DLL，保留用户配置，重启后由测试者手动删除测试程序目录。

格式检查与六个组件的 Clippy 全目标检查通过（警告视为错误）。Ctrl 按下与松开的事件边界修正后，18 项交互测试已随完整检查重新通过。

64 位后台、设置程序和 DLL，以及 32 位配套 DLL 均已生成。两种 DLL 分别在对应位数的进程中成功加载，并找到 `DllGetClassObject`、`DllCanUnloadNow`、`DllRegisterServer`、`DllUnregisterServer` 四个入口；检查时未调用注册入口。

另外在隔离的临时用户目录中运行发布后台，通过真正的 Windows 命名管道与完整词库验证：`jisuanji` 显示“计算机”，Ctrl 调换后空格返回 `computer`；`wojintianxiangqugongyuan` 形成“我今天想去公园”，通过本机模拟 HTTP 服务得到整句英文，Ctrl 调换后空格返回完整的 `I would like to go to the park today.`。请求正文仅含 `text` 和 `target_language` 两个字段。本次验证关闭本地神经重排以固定输入，使用模拟服务，不代表商业模型的自然度测评。

实际离线渲染并检查了中文在左、英文在左的候选窗口，以及“中英文”“云服务”设置页。随包 `预览` 文件夹保留这些画面；它们是渲染预览，未冒充真实应用内的 TSF 操作截图。

## 真机验收边界

未在开发电脑注册测试输入法，因此尚未验收记事本、浏览器、聊天软件或办公软件中真正的 TSF 按键回调与文本上屏，也未执行整套安装/卸载流程。Windows 10 与另一台电脑的兼容性仍需按《双语测试验收》逐项记录。

整句翻译会发送当前未上屏的中文句子给测试者自行配置的服务。自然度、准确度、网络延迟与费用取决于所选模型；自动测试中的固定英文仅用于核对流程，不代表真实模型翻译质量。已上屏的多个中文片段不会自动回收并合成整句译文。

## 源码与重新构建

随包 `source.zip` 包含对应的修改源码；`SOURCE-INFO.txt` 记录基础提交、目标与工具版本，`SHA256SUMS.txt` 记录包内文件摘要。源码保留原许可与数据来源说明。

标准 Windows 构建使用 Rust 1.96.0、MSVC 与 Windows SDK，安装 `i686-pc-windows-msvc` 目标后运行 `apps/windows/bilingual-test/build-package.ps1`。该专用打包脚本生成独立测试包；不要使用原版安装器脚本来打此分支。
