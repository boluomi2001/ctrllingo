# 双语测试验收

本文是 Windows 10/11 x64 的待测清单。真实 TSF、应用内按键、窗口更新、安装与卸载都需要测试者在测试电脑逐项确认；源码检查和模拟请求不能代替真实应用验收。每项保持未勾选，只有实际完成并记录系统、应用和现象后才勾选。测试版使用独立注册标识和数据目录，不覆盖原版；安装前保留旧测试包，出现问题时按随包说明卸载并回装旧包。

## 测试准备

- [ ] 记录 Windows 版本、更新版本、测试包来源和测试应用版本。
- [ ] 将完整测试包解压到独立目录；安装前确认旧包可用于回退。不要覆盖仍在使用的 DLL。
- [ ] 准备记事本及至少一个常用应用。不要在截图或记录中暴露 API 密钥、输入原文或账户隐私。
- [ ] 若测试在线功能，使用自己配置的 OpenAI 兼容服务和密钥，并确认请求可能产生费用。

## 双语候选与 Ctrl 按需翻译

- [ ] 分别选择英语、日语、德语、西班牙语和越南语，检查译词显示、已有译词时 Ctrl 调换主栏，以及所选语言是否用于按需译文；同时开启云联想，确认两项功能可独立工作。
- [ ] 当前高亮没有译词时按 Ctrl，检查请求针对所选学习语言；等待期间按空格不提交、不丢拼音，再按 Ctrl 返回中文。
- [ ] 编辑拼音、改选候选或翻页后，检查译文按新高亮更新；旧响应不得覆盖新候选。检查数字键和点击按所选主栏提交。
- [ ] 检查 Ctrl+C/V/A 和常用 Ctrl 组合仍可用；检查 Esc、删空和失焦后新组合恢复中文主栏。
- [ ] 打开 Ctrl 按需翻译时确认释义兜底与生词本云翻译持续暂停，包括中文主栏及没有组句时。

## 云联想独立性与输入保持

- [ ] 在云联想缺省关闭时验证 Ctrl 按需翻译仍可独立使用。
- [ ] 手动开启云联想后，验证手动联想与 Ctrl 译文各自工作；启用自动联想后确认它会发出请求，并记录可能产生费用。
- [ ] 在连续输入组句过程中点击青简独立托盘品牌图标，检查费用卡片打开后拼音、候选和组合状态均保留。
- [ ] 在组句过程中右键原「中 / 英」图标，检查费用卡片打开后组句状态保留，左键仍执行中英切换。

## 费用卡片与余额

- [ ] 检查卡片同时区分本输入法 Token / 人民币估算费用与官方账户余额，且账户余额保留币种，不被描述为本输入法花费。
- [ ] 检查今日与自首次记账以来累计数据；输入 Token 与输出 Token 相加时缓存命中不重复计数。
- [ ] 检查用途统计显示翻译、云联想与其他/旧记录；旧账本缺用途字段时归入其他/旧记录。
- [ ] 检查缺用量、未知模型、未完成请求能以未知或未完成状态显式显示，估算区间不被写成确定费用。
- [ ] 每次打开卡片都应自动查询官方余额；卡片保持打开时结果更新到原位，快速重复打开时在途请求合并。确认没有独立刷新按钮、60 秒阻断或后台轮询。
- [ ] 查询中检查旧余额及其上次成功时间仍可见；模拟或遇到查询失败时检查旧余额保留且失败状态明确。
- [ ] 检查非官方余额查询服务不会发起官方账户请求；检查账本不保存输入原文或密钥。

## 无服务、取消与切换语言

- [ ] 未配置 API 时验证中文候选、选择和上屏仍可用；断网时重复检查，恢复网络后确认输入正常。
- [ ] 分别按 Esc、删空组合、失焦后重新输入，确认新组合恢复中文主栏。
- [ ] 等待译文期间再次按 Ctrl 返回中文，确认空格可提交中文；旧响应不能覆盖新组合。已发出的请求仍可能计费。
- [ ] 等待日语译文期间改成德语，确认晚到的日语不进入德语候选；重新按 Ctrl 后请求使用新的目标语言。
