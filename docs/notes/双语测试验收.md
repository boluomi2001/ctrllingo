- 不配置整句翻译服务时，先完成第 1–3、5–8 项。若测试整句翻译，请自行填写兼容 OpenAI 的服务地址、模型和密钥。密钥只在本机配置，不要发送到聊天、截图或公开记录中。翻译请求可能产生费用，实际费用取决于所用服务；网络状况也会带来延迟。

## 手工测试步骤

### 1. 双语候选与 Ctrl 切换

1. 在中文输入状态输入一个常见拼音，观察候选栏中的中文候选及其旁边的英文辅助内容。
2. 单独轻按并松开 Ctrl 一次。
3. 观察候选栏主栏位置，再单独轻按并松开 Ctrl 一次。

预期：候选中显示中文及其旁边的英文；第一次 Ctrl 后英文在左、中文在右；第二次 Ctrl 后恢复原来的中文主栏排列。每次都只轻按后松开，不长按。

### 2. 空格、数字选择和方向键选择

1. 输入能产生多个候选的拼音，确保候选栏显示多个项目。
2. 不按数字键先按空格，检查上屏内容。
3. 重新输入拼音，按一个对应非首位候选的数字键；若候选有翻页，再翻页后选择其中一项。
4. 再重新输入拼音，用方向键移动高亮到另一个主栏候选，然后按空格。

预期：空格提交当前高亮的主栏候选；数字键能选择非首位候选及翻页后的候选；方向键改变高亮后，空格提交新高亮的主栏候选，而不是固定提交首位或辅助语言。

### 3. 常用快捷键与 Ctrl 行为

在输入法开启时分别测试：

1. 在文本中使用 Ctrl+C 复制、Ctrl+V 粘贴、Ctrl+A 全选。
2. 使用 Ctrl+Shift（如系统或应用有对应行为，记录其结果）。
3. 按住 Ctrl 不松开一小段时间，再松开；随后继续输入拼音。

预期：复制、粘贴、全选和 Ctrl+Shift 的原有行为仍可使用；单独长按 Ctrl 不应意外切换候选主栏或破坏输入。若 Ctrl+Shift 在该电脑上没有可观察的原有行为，记录“无可观察行为”，不要据此判断通过或失败。

### 4. 连续拼音整句翻译与延迟响应

1. 按测试前准备中的说明，在本机配置兼容 OpenAI 的服务地址、模型和密钥。
2. 输入一段较长的连续拼音，观察组合输入期间英文译文是否随当前句子更新。
3. 在译文尚未返回时继续输入，使句子发生变化；等待网络响应完成，观察较早发出的译文是否会替换当前句子的译文。
4. 可重复输入不同长短的句子，记录请求响应延迟和异常。

预期：英文译文随当前拼音整句更新；网络延迟期间中文输入仍可继续；旧句子的迟到译文不能覆盖新句子的译文。若服务不可用或配置无效，记录服务表现、错误提示和延迟，不要填写或截图暴露密钥。

### 5. 英文模式下无译文时的空格行为

1. 切换到英文模式，输入一段当前没有英文译文的拼音组合。
2. 在组合仍存在时按空格。
3. 再按 Ctrl 切回中文模式，检查当前组合和候选栏。

预期：没有译文时，空格保留组合输入，不会误提交中文；按 Ctrl 切回中文后可继续正常中文输入。记录实际组合是否保留。

### 6. 取消或结束组合后恢复主栏

分别执行以下操作，每次都重新输入一段能显示双语候选的拼音：

1. 按 Esc 取消组合。
2. 用退格键删空组合。
3. 在组合期间点击另一个应用或输入区域，使输入焦点离开，再回到原输入区域开始新组合。

预期：每种操作后新建的组合都以中文为主栏；先前英文主栏状态不会错误地残留到新组合。

### 7. 未配置 API 与断网时的中文输入

1. 在未配置翻译 API 的状态下，输入拼音并选择中文候选、上屏。
2. 若可安全断网，断开网络后重复输入、选择和上屏；测试完恢复网络。

预期：未配置 API 或断网不会妨碍中文候选、选择和上屏。记录是否出现影响中文输入的等待、错误或中断；本项不要求英文译文可用。

### 8. 安装与卸载测试版

1. 仅使用独立副本中的“随包安装测试版脚本”安装测试版，按安装提示完成操作。
2. 确认输入法可在系统输入法列表中启用，并至少完成一次中文输入。
3. 结束测试后，使用“随包卸载测试版脚本”卸载测试版。
4. 检查测试版是否从系统输入法列表移除；若电脑之前已有正式版本，确认正式版本仍可用。

预期：测试版可以按随包脚本安装和卸载；卸载后测试版不再可用，且不破坏独立于测试版的既有版本。脚本名称、文件位置和每步结果均按实际测试包填写；当前文档不预设这些脚本已存在。
