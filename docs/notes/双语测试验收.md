本文用于 Windows 10/11 x64 电脑上的手工验收。请由测试者填写实际系统、应用和结果；开发检查不能代替真实应用验收。安装入口为 `install-test.cmd`，卸载入口为 `uninstall-test.cmd`。测试版沿用独立注册标识和数据目录，不覆盖原版；保留旧测试包以便回装。

## 测试前准备


测试版在系统中显示为“青简双语测试”；配置文件位于 `%APPDATA%\QingjianBilingualTest\config.toml`，与原版 `%APPDATA%\Qingjian\` 目录分开。检查测试版配置时请确认使用测试版目录。

- 使用一台 Windows 10/11 x64 电脑，并记录系统版本和更新版本。
- 准备可输入中文的文本应用，例如记事本。记录实际测试应用及版本；建议另选一个常用应用复测。
- 将测试版文件复制到独立目录，按随包说明运行“随包安装测试版脚本”。不要覆盖已有的正式安装；记录脚本结果。
- 不配置整句翻译服务时，先完成第 1–4、7–9 项。若测试按需整句翻译或余额查询，请自行填写兼容 OpenAI 的服务地址、模型和密钥。密钥只在本机配置，不要发送到聊天、截图或公开记录中；请求可能产生费用，网络也会带来延迟。
- 每项均记录“通过 / 失败 / 未测试”，并写下现象。失败时保留不含密钥等敏感信息的截图或复现步骤。

## 手工测试步骤

### 1. 已有译词时切换主栏

1. 在中文输入状态输入一段有本地译词的拼音，观察中文候选和旁边的英文内容。
2. 单独轻按并松开 Ctrl，观察英文是否成为主栏；再按一次 Ctrl。

预期：第一次 Ctrl 直接切到英文主栏，第二次恢复中文。普通中文组句本身不会自动请求整句翻译。

### 2. 没有译词时按需请求及等待保护

1. 输入能产生多个候选的拼音，确保当前高亮候选没有译词。
2. 轻按并松开 Ctrl，等待译文；等待期间按空格，检查上屏内容。
3. 重新输入同一拼音，按 Ctrl 后在等待期间再按 Ctrl；随后继续输入中文。

预期：第一次 Ctrl 请求当前高亮候选的译文；等待期间空格不提交任何内容，也不丢掉拼音。第二次 Ctrl 回到中文，之后空格可提交中文。已发出的网络请求仍可能继续并产生费用，晚到译文会被忽略；若请求报错，再按 Ctrl 可重试。记录服务错误和响应时间，不要暴露密钥。

### 3. 高亮变化与提交方向

1. 输入有多个候选的拼音并按 Ctrl 切到英文主栏。
2. 编辑拼音、用方向键改选候选，再分别尝试数字键和空格。
3. 重新输入并切到英文主栏后翻页；再点击左右栏的候选。

预期：编辑、改选或翻页使高亮变化后回到中文；需要英文时须在新高亮候选上重新按 Ctrl。数字键提交当前主栏方向的候选；点击候选提交所点栏的内容。

### 4. Ctrl 兼容性与自动请求抑制

1. 分别使用 Ctrl+C、Ctrl+V、Ctrl+A，以及系统或应用支持的 Ctrl+Shift 操作。
2. 先正常输入中文，再按 Ctrl 切到英文主栏，观察「本输入法今日估算」中的请求次数。

预期：常用 Ctrl 快捷键行为不受影响。启用“整句候选翻译”后，普通中文输入不会自动请求整句翻译；自动云联想、释义兜底和生词本云翻译在该开关启用期间持续暂停，不随主栏或组句状态恢复。关闭该开关后，其他功能按旧设置运行。若 Ctrl+Shift 没有可观察的原有行为，记录“无可观察行为”。旧配置和密钥无需修改。

### 5. 连续拼音整句翻译与延迟响应

1. 在本机配置兼容 OpenAI 的服务地址、模型和密钥。
2. 连续输入一段较长拼音，核对中文整句，再按 Ctrl 请求英文。
3. 等待期间继续编辑，观察迟到的旧译文是否会覆盖当前高亮候选；再测试按 Ctrl 撤销英文请求意图和错误后重试。

预期：网络响应期间中文输入仍可继续；旧候选的迟到译文不会覆盖新高亮候选。撤销请求意图不会保证中止已经发出的网络请求，服务仍可能处理并计费。记录请求时间和错误；不要在截图或记录中暴露密钥。

### 6. 用量估算、账户余额与快照

1. 右键点击右下角「中 / 英」按钮，查看「本输入法今日估算」及 DeepSeek 官方账户余额；左键点击按钮确认仍会切换中英文。
2. 打开「用量与费用…」对话框，关闭后重新打开；等待至少 60 秒后重新打开余额菜单，并在另一应用中查看是否共用查询间隔。

预期：估算展示新版启用后的请求次数、token 和金额范围或“未知”；只有官方 `api.deepseek.com` 上的 `deepseek-flash`、`deepseek-v4-flash` 和 `deepseek-v4-flash-vision-exp` 套用 2026-10-19 官方人民币价格。旧数据不补算，之前平台显示的 0.66 元不回算。工作日高峰的节假日不确定、或缺少缓存 token 明细时显示费用范围；用量缺失或服务未映射时显示“未知”。DeepSeek 账户余额不等于今日扣费；余额查询仅在打开菜单时发起，所有应用共用 60 秒间隔。对话框是打开时的快照，关闭再打开刷新。账本中不得出现句子或密钥。

### 7. 取消或结束组合后恢复主栏

分别执行以下操作，每次都重新输入一段能显示双语候选的拼音：

1. 按 Esc 取消组合。
2. 用退格键删空组合。
3. 在组合期间点击另一个应用或输入区域，使输入焦点离开，再回到原输入区域开始新组合。

预期：每种操作后新建的组合都以中文为主栏；先前英文主栏状态不会错误地残留到新组合。

### 8. 未配置 API 与断网时的中文输入

1. 在未配置翻译 API 的状态下，输入拼音并选择中文候选、上屏。
2. 若可安全断网，断开网络后重复输入、选择和上屏；测试完恢复网络。

预期：未配置 API 或断网不会妨碍中文候选、选择和上屏。记录是否出现影响中文输入的等待、错误或中断；本项不要求英文译文可用。

### 9. 安装与卸载测试版

1. 仅使用独立副本中的“随包安装测试版脚本”安装测试版，按安装提示完成操作。
2. 确认输入法可在系统输入法列表中启用，并至少完成一次中文输入。
3. 结束测试后，使用“随包卸载测试版脚本”卸载测试版。
4. 检查测试版是否从系统输入法列表移除；若电脑之前已有正式版本，确认正式版本仍可用。

预期：测试版可以按随包脚本安装和卸载；卸载后测试版不再可用，且不破坏独立于测试版的既有版本。记录实际脚本日志与每步结果。
