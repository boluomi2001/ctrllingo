# 第三版费用面板与多语言验证记录

日期：2026-10-20。交付为独立 Windows x64 双语测试包，不是正式发布。GPT-6 Luna 子任务负责明确的实现和资料整理，主代理负责方案、代码审查、修正及下面的验证结论。

## 本轮实现

- 右键测试版独立青简托盘图标，或右键原「中 / 英」模式图标，直接打开用量卡片。保留今日 / 累计、目标语言、详细记录与设置入口。
- 卡片展示本输入法输入、输出及缓存 Token、费用估算、翻译与云联想请求次数，以及 DeepSeek 官方账户余额。缓存命中包含在输入中，不重复相加；账户余额不用于推算本输入法消费。
- 没有刷新按钮。每次打开都发起余额查询，仅合并尚未结束的请求；没有 60 秒缓存阻断，也不在后台轮询余额。卡片可见时的本地快照更新不发送网络请求。查询中及失败时保留上次余额和成功时间。
- 中文候选可以通过 Ctrl 请求英语、日语、西班牙语、越南语或德语译文，再按空格输出。仅覆盖当前五种目标语言，没有声称支持世界上所有语言。
- 云联想与 Ctrl 翻译分别控制；首次升级备份测试版配置并关闭云联想、自动联想，之后保留用户主动选择。服务、模型和密钥配置保留。
- 桌宠留在后续版本，本包没有加入桌宠或参考项目素材。

## 仍需在安装后验证

未在本轮运行安装 / 卸载脚本，未替换用户原版输入法或注销 Windows。实际 Windows TSF 的单独 Ctrl 松键、记事本与常用应用上屏、物理右键图标、语言菜单点击、多屏 / 多种缩放比例、真实 API 余额与翻译质量，需按随包《双语测试验收》测试。

独立托盘回调验证使用真实窗口消息；没有把它写成用户物理点击系统托盘的验证结果。未验证的真实应用检查仍保持未勾选。
